# Study Materials — Subsystem Documentation

Parent: [`../DOCUMENTATION.md`](../DOCUMENTATION.md)

Downloadable reference/vocabulary documents — the simplest subsystem in `resources/`, no test logic at all.

## Pages

| File | Purpose |
|---|---|
| `index.php` | Catalog of available downloads (vocabulary sets: astronomy, restaurants, sustainable food, technology, etc.) |
| `view.php` | Viewer/preview page for a selected material before download |

## Assets

Actual files live in `academy/assets/downloads/vocabulary/` (4 documents at last check). To add a new material: drop the file there, add a catalog entry in `index.php`.
