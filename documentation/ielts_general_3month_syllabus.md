# IELTS General — 3-Month Masterclass Syllabus
**Version 1.0 | May 2026**

## Structure
- 12 Weeks · 2 Classes/Week · 24 Total Sessions
- 21 Teaching classes + 3 Full Mock Tests (end of each month)
- 4 Practice Test Sets × 4 sections each = 16 section practices, one per class across 16 of 21 teaching classes
- 5 classes are free of practice sections (orientation, diagnostic review, heavy-content sessions)
- Every teaching class includes a Quiz and a Take-home exercise

## Practice Test Distribution
Each set covers all 4 skills, sections spread across lessons so students do one section per class.

| Set | Listening | Reading | Writing | Speaking |
|---|---|---|---|---|
| PT Set 1 | Class 3 | Class 4 | Class 5 | Class 6 |
| PT Set 2 | Class 7 | Class 9 | Class 10 | Class 11 |
| PT Set 3 | Class 12 | Class 13 | Class 14 | Class 17 |
| PT Set 4 | Class 18 | Class 19 | Class 21 | Class 22 |

## Mock Tests
| Mock | Session | Covers |
|---|---|---|
| Mock Test 1 | Class 8 (end of Month 1) | Full exam — all 4 skills, timed |
| Mock Test 2 | Class 16 (end of Month 2) | Full exam — all 4 skills, timed |
| Mock Test 3 | Class 24 (end of Month 3) | Full exam — all 4 skills, timed |

## MONTH 1 — FOUNDATIONS (Weeks 1–4)

---

### Week 1

#### Class 1 — Course Orientation & IELTS General Overview
**Skills:** All sections
**Lesson codes:** 00A
**Topics:**
- Welcome and programme overview
- IELTS General vs Academic — key differences
- Format of all 4 sections: Listening, Reading, Writing, Speaking
- Band score calculation and what each band means
- How classes, quizzes, and take-homes work

**Videos:**
- Alessandra_opening_sequence_short.mp4
- Seda_openingsequence_full.mp4
- IELTS Speaking threecandidates_openingsequence.mp4

**Practice Test:** None (orientation class)

**Quiz:** 10 IELTS format knowledge questions (section timings, question counts, band ranges)

**Take-home:** Self-assessment grid — rate all 4 skills 1–5 honestly; write 3 sentences on your weakest area and why

---

#### Class 2 — Diagnostic Mini Mock + Review
**Skills:** All sections
**Lesson codes:** 00B, 00C, 00X
**Topics:**
- Abridged mini mock test covering all 4 skills
- Review of Writing and Speaking responses
- Band Descriptor walkthrough — what examiners look for
- Strengths and weaknesses identified per student
- Guided corrections and self-assessment framework

**Videos:**
- IELTS WRITING SECTION OVERVIEW.mp4
- IELTS General Writing Test Overview.mp4

**Practice Test:** None (diagnostic class — the mini mock itself serves as baseline)

**Quiz:** Band descriptor identification drill — match responses to band levels

**Take-home:** Draft 1 informal letter from a given prompt · Record a 2-minute Speaking Part 1 response on home/daily life

---

#### Class 3 — Listening: Form Completion & Gap-fill · Speaking: Introduction & Fluency
**Skills:** Listening, Speaking
**Lesson codes:** SL1, SL2
**Topics:**
- Listening Parts 1 & 2 — form completion and gap-fill strategies
- Prediction before the recording plays
- How to handle numbers, names, and dates
- Speaking introduction — first impressions, fluency tips, coherence

**Videos:**
- IELTS_L1_PART_1_LISTENING_CLASS_1_FORM Completion.mp4

**Quiz:** Gap-fill prediction strategies — 10 questions on what to write in blank types

**Take-home:** Record Speaking Part 1 responses on 3 topics: hobbies, hometown, work/study (2 minutes each)

#### Class 4 — Reading: Skimming & Scanning · Writing Task 1: Vocabulary & Registers

**Lesson codes:** SL3, SL4
**Topics:**

- How to manage 3 passages in 60 minutes

#### Class 5 — Listening: Multiple Choice · Speaking Part 1: Common Topics & Questions

**Videos:**

**Quiz:** MCQ elimination drill — 10 questions from a recorded extract

#### Class 6 — Reading: True/False/Not Given · Writing Task 1: Formal Letters
**Skills:** Reading, Writing
**Lesson codes:** SL7, SL8
**Topics:**
- True/False/Not Given vs Yes/No/Not Given — the critical difference

**Videos:**
- IELTS_R4_PARAPHRASING_CLASS_1_480p.mp4

**Quiz:** TFNG vs YNNG decision drill — 10 statements, classify each correctly

**Take-home:** Write a formal complaint letter to a company about a product (150 words minimum)

### Week 4 — End of Month 1

#### Class 7 — Listening: Map Listening · Speaking Part 2: Topic Development
**Skills:** Listening, Speaking
**Lesson codes:** SL9, SL10
**Topics:**

- Parts 2 & 3 map/plan labelling strategies

**Videos:**

**Practice Test:** PT Set 2 — Listening (Parts 1, 2 & 3, timed)

**Quiz:** Map orientation drill + Part 2 cue card planning practice (3 cards, 1 minute each)

**Take-home:** Prepare 3 Part 2 cue card outlines — write 1-minute notes and a 2-minute speech plan for each

---

#### Class 8 — MOCK TEST 1 *(Full Timed Exam — End of Month 1)*
**Skills:** All
**Topics:**
- Listening (30 min + 10 min transfer)
- Reading (60 min — 3 passages)
- Writing Task 1 + Task 2 (60 min total)
- Speaking simulation (Parts 1, 2, 3)

**Output:** Band score estimates · Strengths/weaknesses updated · Month 2 improvement plan

**Skills:** Writing
**Lesson codes:** SL24, Bonus: Opinion essays — structuring arguments & supporting evidence
**Topics:**

- How to develop and support arguments with specific examples

- IELTS_WT2_4_INTRODUCTIONS_CLASS_1_480p.mp4

**Practice Test:** PT Set 4 — Listening (Parts 1–4, full timed)

**Quiz:** PEEL paragraph builder — 3 topic sentences given, write the full paragraph using PEEL

#### Class 19 — Writing Task 2: Balanced Conclusions · Discussion Essays
**Skills:** Writing
**Lesson codes:** SL28, Bonus: Discussion essays — presenting multiple viewpoints
**Topics:**
- Balanced conclusions — summarising both sides without introducing new ideas
- How to avoid repetition in conclusions
- Discussion essays — presenting arguments for each side fairly
- Signposting and discourse markers for discussion essays

**Videos:**
- IELTS_WT2_4_INTRODUCTIONS_CLASS_2_480p.mp4

**Practice Test:** PT Set 4 — Reading (all 3 passages, timed)

**Quiz:** Conclusion quality assessment — rate 5 sample conclusions against band descriptors and explain

**Take-home:** Write 2 full Task 2 essays: one opinion essay, one discussion essay (timed — 40 min each, different days)

**Skills:** Writing
**Topics:**

- IELTS Writing Task 2 Overview.mp4

**Quiz:** Essay type identification drill — given 5 prompts, name the essay type and write a 3-point outline

**Take-home:** Create a mind map plan (no full essay) for one prompt of each of the 5 essay types

**Topics:**
